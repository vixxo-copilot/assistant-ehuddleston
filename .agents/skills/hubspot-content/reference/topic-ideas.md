## How to present suggestions

When the user asks for ideas or has not named a topic:

1. Briefly state audience (VP+ facilities, multi-site retail/commercial).
2. List 5–8 rows from the table above (or a fresh subset if they name an industry).
3. Ask: **"Pick a number, name your own topic, or paste a brief."**
4. Do not stage until they confirm a topic.

## Custom topics

If the user supplies a free-form prompt:

- Derive a **campaign slug**: lowercase, hyphens, year suffix (`topic-name-2026`).
- Confirm audience, primary CTA (`https://www.vixxo.com`), and target date if missing.
- Proceed with compose → stage → `REVIEW.md`.
