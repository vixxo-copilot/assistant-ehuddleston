# IFM messaging principles

Use for Critique and as the quality bar on any Build copy.

## Claim stack (required)

Every external claim must be one of:

1. **Outcome** — what changed for a portfolio (downtime, cost variance, cycle
   time, inspection risk). Needs a number or a bounded range *from real
   proof*. If you lack the number, write the mechanism and mark the proof
   gap instead of faking it.
2. **Mechanism** — how the operating model produces the outcome (dispatch
   rules, licensed network, QA, NTE, after-hours coverage).
3. **Scope** — where it is true (trade, banner, geography, hours). Unscoped
   national claims get killed in procurement.

Never lead with personality ("we care") or category clichés ("end-to-end").

## The IFM copy test

Score each asset 0–2 on each line (10 is excellent):

| Test | 0 | 2 |
| --- | --- | --- |
| Alternative named | Implies "vs nothing" | Names in-house, giant IFM, regional, or software |
| Committee | One vague "you" | Clear primary reader + a forwardable line for a second role |
| Proof | Adjective | Metric, site count, process, or honest "proof needed" callout |
| Specificity | Any FM company could run this ad | Retail/restaurant/multi-site tempo is obvious |
| Risk | Hidden | Addresses downtime, compliance, or invoice leakage |
| CTA | "Learn more" | Matches stage (guide, RFP checklist, coverage conversation) |

Rewrite anything under 7. Show the rewritten version, not only the score.

## Proof architecture

Rank proof buyers actually trust in this market:

1. Named operational KPIs (cycle time, first-time fix, invoice accuracy)
2. Vertical references (same banner type, similar site count)
3. Coverage / licensing / compliance artifacts
4. Implementation plan (first 90 days)
5. Analyst/association presence (credibility, not the close)
6. Brand advertising (useful for recall, insufficient to win)

If marketing is spending on (6) while (1)–(4) are thin, say so.

## Message houses by competitor type

| They would buy instead | Winning contrast | Losing contrast |
| --- | --- | --- |
| In-house + locals | Variance, after-hours, national brand standard | "Outsource everything" ideology |
| CRE IFM giant | Tempo, store-level reality, cost-to-serve | "We're bigger" or "we're cheaper" only |
| Regional SP | One operating system vs patchwork | Insulting local relationships |
| CMMS only | Software does not turn a wrench | Pretending you are a software company |

## Voice

- Operational, specific, calm. Facilities leaders distrust hype.
- Short sentences. Numbers before metaphors.
- Match Vixxo brand guidelines on designed artifacts
  (`vixxo-brand-guidelines`). Messaging substance still comes from this file.

## Critique output shape

1. Score table
2. The single most expensive problem (usually unscoped claim or missing
   committee)
3. Rewrite of the hero / primary ad / subject line
4. Proof gap list for the operator to fill with real data
5. Handoff skill if they want a full rewrite (`copywriting`, `copy-editing`,
   `ad-creative`, `sales-enablement`)
