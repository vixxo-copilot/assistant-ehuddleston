# Skill routing (after IFM framing)

This skill sets the IFM lens, then hands off. Do not duplicate playbooks.

## Start here vs hand off

| Job | This skill does | Then read / run |
| --- | --- | --- |
| Teach, brief, critique IFM judgment | Yes | Domain refs in this folder |
| Positioning / ICP / message house | Frame in IFM terms | `product-marketing` |
| AEO, citations, AI answers, page revamp | Snapshot + IFM implications | `vixxo-profound-aeo` → `hubspot-page-aeo` |
| Website copy | IFM copy tests | `copywriting` / `copy-editing` |
| Content roadmap | Capture vs create filter | `content-strategy` |
| SEO on-page | After Profound | `seo-audit`, `schema`, `ai-seo` |
| Paid / ABM / LinkedIn / search | Channel physics | `ads`, `ad-creative` |
| Battle cards / competitor pages | Narrative rules | `competitors`, `competitor-profiling` |
| Decks, one-pagers, objections | Committee + proof | `sales-enablement` |
| Email / sequences | Trigger + draft-then-approve | `emails`, `cold-email` |
| Social posts | Only if committee-useful | `social` |
| Offers / magnets | Stage-matched | `offers`, `lead-magnets` |
| Measurement | IFM KPI set | `analytics`, `attribution` |
| Multi-advisor debate | After IFM frame | `marketing-council` |
| Ideas list | Filter through IFM laws | `marketing-ideas`, `marketing-plan` |
| Brand styling of artifacts | — | `vixxo-brand-guidelines` |

## Rarely right for IFM core motion

Treat as exception-only: `aso`, `paywalls`, `popups`, `signup` PLG, `sms`
consumer, `influencer-marketing`, `churn-prevention` SaaS cancel-flow
(unless they explicitly have a self-serve product). If asked, explain why
the physics are wrong, then comply only with an IFM rewrite.

## Build-mode sequence

1. IFM diagnose (mode, buyer, alternative, proof gap)
2. Load one domain ref
3. Name the 1–3 skills to run next
4. Either run them in the same turn (if the user wants the asset now) or
   stop after the brief if they only wanted the plan
